# Scoring rubric

The **core question**: *Did the user stay in discovery about the buyer's world, or did they
shift to pushing their solution?* Weight this above everything else.

| Score | What it looks like |
|---|---|
| **5 — Pure PULL** | Stayed curious about the buyer's project the whole time. Uncovered (or correctly ruled out) all four PULL elements with open questions. Only described the solution after PULL was clear, and tied it to the buyer's own words — or the buyer asked for it. If there was no PULL, recognized it and exited gracefully without pitching. |
| **4 — Mostly pull** | Strong discovery, found most of PULL. One small slip (an early feature mention, one leading question) but recovered. |
| **3 — Mixed** | Some good questions, but drifted into describing the product before understanding the project, or missed a key element (usually *Unavoidable* or *Looking*). |
| **2 — Mostly push** | Pitched early and often. Questions were leading ("Wouldn't it be great if…?", "Do you struggle with X?"). Treated pain or politeness as demand. |
| **1 — Pure push** | Demo/pitch from the start, talked more than the buyer, tried to convince or overcome objections, or kept selling to a no-PULL buyer. |

## Push signals to flag (quote the user's line)
- Mentioning features/benefits before the buyer described a project.
- Leading or hypothetical questions that plant a problem.
- "Educating" the buyer on why they *should* care.
- Handling an objection by arguing instead of getting curious.
- Asking for a meeting/demo/trial before PULL was established.
- Continuing to sell after signs of no PULL (enthusiastic-but-vague, no project, no timeline).

## Pull signals to credit
- "What are you working on right now?" / "What's the priority this quarter?"
- "Why now?" / "What happens if this doesn't get done?" (Unavoidable)
- "What have you tried?" / "How are you handling it today?" (Looking)
- "What's not working about that?" (Lacking)
- Reflecting the buyer's words back; letting silence work; short talk-time.
- Honest disqualification: "Sounds like this isn't a priority right now — is that fair?"

## Scorecard format (keep it short)

```
---
## PULL Score: X/5 — <one-phrase verdict>

**Hidden truth:** <PULL or NO PULL> — <one line per P/U/L/L: found ✅ / missed ❌ / n/a>

**Did you push?** <Yes/No/Partly> — first push moment: "<quoted user line>" (turn N)

**What worked**
- "<quoted line>" — why

**What to fix**
- "<quoted line>" — why

**Try this instead:** "<quoted push line>" → "<rewritten pull question>"

Run it again, try another scenario (1–8), or `random`?
```
